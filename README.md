One emoji for a dream vacation: Mount Fuji 🗻 — a single snow-capped peak that is a whole trip in one glance. No words, no beach cliché, just the mountain you save up to see.

## Run it

```sh
python3 main.py
```

It writes exactly one emoji to `/output/entry.txt`.
